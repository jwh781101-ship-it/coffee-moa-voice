아이폰 홈 화면에 추가하기

  1. 이 페이지를 Safari에서 열어 주세요.
    먼저 아래 앱 열기 버튼을 누르지 말고 이 페이지에서 추가합니다.
  2. Safari의 공유를 누르고 홈 화면에 추가를 선택합니다.
  3. 미리보기에서 위 커피모아 그림과 이름을 확인한 뒤 추가를 누릅니다.

홈 화면에 추가하기

아래 버튼을 눌러 설치 창이 나타나면 직접 확인해 주세요. 사용자 확인 없이 자동으로 추가할 수 없습니다.

설치 준비 중일 수 있습니다. 창이 나타나지 않으면 아래 메뉴를 이용해 주세요.

  1. Chrome: 오른쪽 위 ⋮ 메뉴에서 앱 설치 또는 홈 화면에 추가를 선택합니다.
  2. 삼성 인터넷: 메뉴에서 페이지 추가 대상 → 홈 화면을 선택합니다.

휴대전화 홈 화면에 추가하기

휴대전화에서 이 페이지를 열어 주세요. 아이폰은 Safari 공유 메뉴에서, 안드로이드는 Chrome 또는 삼성 인터넷 메뉴에서 홈 화면에 추가할 수 있습니다.

이 페이지는 아이콘 추가용입니다. 기존 GAS 앱과 서버 데이터는 변경하지 않습니다. 새 바로가기가 정상적으로 열리는 것을 확인한 뒤 기존 ‘커’ 아이콘을 정리해 주세요.
